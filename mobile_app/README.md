# SafeZone AI Mobile

Flutter + Kotlin + LiteRT Android prototype with Arabic RTL screens and replaceable on-device models.

The app includes model import and metadata validation, model switching and rollback, camera inference, temporal gate episodes, local event history, statistics, and a CPU/GPU benchmark screen. Model weights are not bundled; bring an authorized model that satisfies `docs/MODEL_CONTRACT.md` and `docs/MODEL_COMPATIBILITY.md`.

Start with the repository-level setup in `../README.md`, then review `docs/RUN_AND_DEPLOYMENT_GUIDE_AR.md`. Historical implementation and verification documents describe prototype checks only; they do not establish production readiness or field accuracy.
