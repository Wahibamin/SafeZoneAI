# ADR-006: سياسة الخصوصية الصارمة — عدم حفظ صور أو فيديو أو بصمات وجه

## الحالة
معتمد (Accepted) — 2026-11-18

## القرار والتفسير
لا يقوم التطبيق بحفظ أي إطارات كاميرا أو صور أو مقاطع فيديو أو بصمات حيوية مطلقاً، ولا يطلب صلاحية الإنترنت أو التخزين العام. التسجيل التاريخي للأحداث النصية غير الشخصية معطل افتراضياً (`event_logging_enabled = false`).
