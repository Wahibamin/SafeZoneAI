# ADR-005: قاعدة بيانات SQLite موحدة مع ترقيات (Migrations) مرقمة

## الحالة
معتمد (Accepted) — 2026-11-18

## القرار والتفسير
اعتماد ملف قاعدة بيانات واحد `safezone_mobile.db` كمصدر وحيد للحقيقة، مع تفعيل `PRAGMA foreign_keys = ON` وتنفيذ الجداول عبر ترقيات مرقمة (V1: النماذج والإعدادات، V2: عينات الأداء، V3: الجلسات والأحداث الاختيارية).
