# ADR-003: حفظ ملفات النماذج خارج APK وخارج SQLite

## الحالة
معتمد (Accepted) — 2026-11-18

## القرار والتفسير
يتم استيراد ملفات `.tflite` عبر منتقي ملفات النظام (Android SAF) ونسخها إلى المساحة الخاصة بالتطبيق `files/models/<model-id>/weights.tflite` مع حساب بصمة SHA-256، بينما تحتفظ قاعدة البيانات `safezone_mobile.db` بالبيانات الوصفية والمسار النسبي فقط.
