# ADR-004: حصر النسخة الأولى في نماذج YOLO Detection المتوافقة

## الحالة
معتمد (Accepted) — 2026-11-18

## القرار والتفسير
يدعم الإصدار الأول نماذج الكشف (`task = detect`) بصيغة `tflite` المتوافقة مع عقد التنسورات المعتمد (مثل YOLO11n لكشف الكمامات)، ويرفض التطبيق أي ملف `.tflite` معطوب أو مخصص للتصنيف/التجزئة برسالة واضحة دون ادعاء تشغيل أي نموذج عشوائي.
