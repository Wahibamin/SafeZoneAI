# ADR-002: عزل محرك الاستدلال خلف واجهة InferenceEngine قابلة للاستبدال

## الحالة
معتمد (Accepted) — 2026-11-18

## القرار والتفسير
عدم ربط واجهات التطبيق أو منطق السلامة مباشرةً بمكتبة طرف ثالث؛ بل استخدام واجهة `InferenceEngine` تدعم التحميل (`load`)، الإحماء (`warmup`)، الاستدلال (`infer`)، والتبديل الفوري (`switchModel`) مع التراجع التلقائي عند الفشل.
