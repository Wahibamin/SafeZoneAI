# ADR-007: اعتماد حالة المراجعة (REVIEW) كحالة أساسية

## الحالة
معتمد (Accepted) — 2026-11-18

## القرار والتفسير
عندما تكون الثقة أقل من العتبة المحددة أو تتعارض القراءات أو لا تتوفر أدلة كافية في وضع البوابة، يُصدر النظام حالة `REVIEW` صريحة بدلاً من إخفاء الحدث أو اختلاق حكم التزام/مخالفة غير مؤكد.
